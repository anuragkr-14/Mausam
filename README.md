# 🌦️ MAUSAM – Personalized Weather

> **Weather that understands you.**

MAUSAM is a **personalized, multilingual weather application** designed to transform weather data into meaningful, lifestyle-specific information.

Instead of presenting users with only temperature, humidity, and weather conditions, MAUSAM adapts the experience according to the user's **profile, location, language, and lifestyle needs**.

Whether the user is a **fitness enthusiast, health-conscious individual, traveler, or daily commuter**, MAUSAM presents weather information in a way that is easier to understand and more relevant to their everyday decisions.

---

## ✨ Key Highlights

- 🌍 **Multilingual Experience** – Supports multiple Indian languages to make weather information more accessible.
- ☁️ **Live Weather Data** – Fetches current weather and forecast information using the **Open-Meteo Forecast API**.
- 👤 **Personalized Profiles** – Weather insights adapt according to the selected lifestyle profile.
- 📍 **City-Based Weather** – Users can select a supported city and receive weather information for that location.
- 💡 **Actionable Insights** – Converts weather conditions into profile-specific recommendations.
- 🔄 **Dynamic Language Switching** – Users can change the application language without restarting the application.
- ↔️ **RTL Support** – Urdu automatically switches the interface to a right-to-left layout.
- 🌡️ **Weather Metrics** – Displays important parameters such as temperature, feels-like temperature, humidity, wind speed, precipitation, visibility and UV index.
- 📅 **Forecast Information** – Provides upcoming weather information along with daily and hourly weather data.
- 🧩 **Component-Based Architecture** – Built using reusable React components for scalability and maintainability.
- 📱 **Responsive Interface** – Designed to work across desktop and mobile screen sizes.
- ⚡ **Fast Frontend** – Powered by Vite for fast development and optimized production builds.

---

## 🎯 Problem

Traditional weather applications primarily present **raw weather measurements**.

However, the same weather condition can affect different people differently.

For example:

- 🏃 A fitness user may need to know whether outdoor exercise is comfortable.
- ❤️ A health-focused user may need information about heat, humidity and UV conditions.
- ✈️ A traveler may care about visibility, rain probability and suitable conditions for travel.
- 🚗 A commuter may need weather information that helps with daily travel planning.

MAUSAM addresses this gap by transforming weather information into **context-aware and user-oriented insights**.
